# 🍳 레시피 노트 — 설치 가이드

인스타 캡션과 네이버 블로그 글에서 레시피를 뽑아 재료 · 양념 · 순서로 정리해 모아보는 앱이에요.

```
인스타 / 네이버 블로그 [공유] → 단축어 "레시피 저장" → Apps Script(정리) → 구글 시트
                                                                        ├ recipes 탭: 정리된 레시피 (+ 출처 링크)
                                                                        └ links 탭: 레시피가 없는 링크 모음
                                          아이폰 홈 화면 웹앱(index.html)에서 [레시피] [링크 모음] 탭으로 보기
```

| 상황 | 결과 |
|---|---|
| 인스타 + 캡션 복사함 | 레시피로 정리 · 출처 링크 함께 저장 |
| 인스타 + 캡션 없음 | **링크 모음**에 따로 저장 (나중에 캡션 붙여넣으면 레시피로 이동) |
| 네이버 블로그 | 링크만 공유하면 글 본문을 불러와서 레시피로 정리 · 출처 링크 함께 저장 |

**대표 사진:** 저장할 때 인스타·블로그의 대표 이미지를 자동으로 가져와 구글 드라이브 `레시피 노트 사진` 폴더에 보관해요. 못 가져오면 앱에서 직접 올릴 수 있고, 사진이 없으면 분류 아이콘(🥢🍲🍚🍜🍞🍰🥗)으로 보여요.

| 파일 | 역할 |
|---|---|
| `Code.gs` | 구글 Apps Script 서버. 캡션·블로그 글 정리, 중복 확인, 시트 저장 |
| `index.html` | 아이폰에서 보는 웹앱 (GitHub Pages에 올림) |

---

## 1. 구글 시트 + Apps Script (10분)

> 이 단계는 **PC(크롬 브라우저)**에서 하는 게 편해요. 아이폰에서는 Apps Script 편집기가 잘 안 열려요.

### 1-1. 시트 만들기
1. [sheets.google.com](https://sheets.google.com) → **빈 스프레드시트(+)** 를 눌러요.
2. 왼쪽 위 "제목 없는 스프레드시트"를 눌러 이름을 `레시피 노트`로 바꿔요.

### 1-2. 코드 붙여넣기
1. 시트 상단 메뉴 **확장 프로그램 → Apps Script**를 눌러요. 새 탭에 편집기가 열려요.
2. 왼쪽 위 "제목 없는 프로젝트"를 눌러 이름을 `레시피 노트`로 바꿔요. (나중에 권한 화면에 이 이름이 나와요)
3. 가운데 편집 창에 있는 `function myFunction() { … }`을 **전부 지우고**, 받은 `Code.gs` 내용을 통째로 붙여넣어요.
4. **💾 저장 아이콘**(또는 `Ctrl + S`)을 눌러요.

### 1-3. setup 실행해서 TOKEN 받기
1. 편집 창 위쪽 도구 모음을 보면 **▷ 실행** 버튼과 **디버그** 버튼 오른쪽에 함수 이름 선택 칸이 있어요.
   - 처음엔 `onOpen`이 선택돼 있을 수 있어요. 눌러서 **`setup`**으로 바꿔요.
2. **▷ 실행**을 눌러요.
3. 처음 한 번은 **권한 허용** 창이 떠요. 아래 순서대로 눌러요.
   1. "승인 필요" 창 → **권한 검토**
   2. 내 구글 계정 선택
   3. "Google에서 확인하지 않은 앱" 경고 → 왼쪽 아래 **고급** → **레시피 노트(으)로 이동(안전하지 않음)**
      - 내가 만든 스크립트라서 뜨는 경고예요. 다른 사람이 아니라 내 계정에서만 돌아가요.
   4. 권한 목록 확인 → **허용** (또는 "모두 선택" 체크 후 **계속**)
4. 화면 아래에 **실행 로그** 창이 열리면서 이렇게 나와요.
   ```
   오후 1:30:12   알림   실행이 시작됨
   오후 1:30:13   정보   TOKEN: 3f9a1c7e2b4d8a60
   오후 1:30:13   정보   AI 정리: 꺼짐 (무료 규칙 정리)
   오후 1:30:13   정보   시트의 '설정' 탭 B2 칸에서도 TOKEN을 볼 수 있어요.
   오후 1:30:14   알림   실행이 완료됨
   ```
   `TOKEN:` 뒤의 **16자리 영문+숫자**(예: `3f9a1c7e2b4d8a60`)가 토큰이에요. 복사해 두세요.
5. 시트 탭으로 돌아가면 아래쪽에 `recipes`, `links`, **`설정`** 탭이 생겨 있어요.
   - **`설정` 탭 B2 칸**(노란 칸)에도 같은 토큰이 적혀 있어요. 실행 로그를 놓쳤으면 여기서 보면 돼요.

> 🔑 **토큰이 뭐예요?** 내 레시피 서버의 비밀번호 같은 거예요. 웹앱과 단축어가 요청할 때 이 값을 같이 보내서, 토큰을 모르는 사람은 레시피를 보거나 저장할 수 없어요. `setup`을 다시 실행해도 토큰은 바뀌지 않아요.
>
> 💡 시트를 새로고침하면 상단 메뉴에 **🍳 레시피 노트 → 초기 설정 / 토큰 보기**가 생겨요. 언제든 눌러서 토큰을 다시 확인할 수 있어요.
>
> 💡 함수 선택 칸에서 `testParse`를 골라 실행하면 샘플 캡션이 어떻게 정리되는지 실행 로그로 볼 수 있어요.

### 1-4. 웹 앱으로 배포해서 URL 받기
1. 편집기 오른쪽 위 파란 **배포** 버튼 → **새 배포**
2. "유형 선택" 옆 **⚙️ 톱니** → **웹 앱** 선택
3. 아래처럼 채워요.
   | 항목 | 값 |
   |---|---|
   | 설명 | `레시피 노트` (아무거나) |
   | 다음 사용자 인증 정보로 실행 | **나 (내 이메일)** |
   | 액세스 권한이 있는 사용자 | **모든 사용자** |
   - "모든 사용자"여도 **토큰이 없으면 아무것도 못 해요.** 단축어가 로그인 없이 접속하려면 이 설정이 필요해요.
4. **배포** → (권한을 한 번 더 물어보면 1-3의 3번과 같이 허용)
5. "배포를 업데이트했습니다" 창에 나온 **웹 앱 URL**을 **복사**해요.
   - `https://script.google.com/macros/s/AKfycb…긴 문자…/exec` 처럼 **`/exec`로 끝나는 주소**예요.
   - 나중에 다시 보려면: **배포 → 배포 관리** → 활성 배포 선택 → 웹 앱 URL

이제 **TOKEN**과 **웹 앱 URL** 두 가지를 손에 넣었어요. 2단계(웹앱)와 3단계(단축어)에서 이 두 값을 써요.

> ⚠️ 이전 버전을 이미 배포했다면 새 `Code.gs`를 붙여넣고 **`setup`을 한 번 더 실행**한 뒤 아래 방법으로 다시 배포하세요. (`links` 탭과 `source` 열이 추가돼요)
>
> ⚠️ 나중에 `Code.gs`를 고치면 **배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포**를 해야 반영돼요. URL은 그대로예요.

### (선택) AI 정리 켜기
기본은 무료 규칙 기반 정리예요. 캡션 형식이 들쭉날쭉해서 정리가 자주 틀리면 AI 정리로 바꿀 수 있어요.

- Apps Script 왼쪽 **⚙️ 프로젝트 설정 → 스크립트 속성 → 속성 추가**
- 속성 `CLAUDE_API_KEY`, 값에 Claude API 키를 넣고 저장
- 키를 지우면 다시 무료 규칙 정리로 돌아가요. 이미 저장된 레시피는 상세 화면의 **다시 정리하기**로 새로 정리할 수 있어요.

## 2. 웹앱 올리기 (GitHub Pages)

1. GitHub에 새 저장소(예: `recipe-note`)를 만들고 `index.html`을 올려요.
2. 저장소 **Settings → Pages → Branch: main / root → Save**
3. 잠시 후 나오는 주소(`https://아이디.github.io/recipe-note/`)를 아이폰 **Safari**로 열어요.
4. 오른쪽 위 **⚙︎ 설정**에 1단계의 **웹 앱 URL**과 **TOKEN**을 넣고 **연결**을 눌러요.
5. Safari 공유 버튼 → **홈 화면에 추가** → 앱처럼 쓰면 돼요.

> 서버 주소와 토큰은 아이폰 브라우저에만 저장되고 GitHub에는 올라가지 않아요. 그래서 저장소가 공개여도 다른 사람이 레시피를 볼 수 없어요.

## 3. 단축어 "레시피 저장" 만들기 (10분, 아이폰에서)

준비물: 1단계의 **웹 앱 URL**과 **TOKEN**. 아이폰 메모에 붙여두면 복사하기 편해요.

### 3-1. 새 단축어 만들기
1. 아이폰 **단축어** 앱을 열어요. (없으면 앱스토어에서 "단축어" 설치)
2. 아래 **단축어** 탭 → 오른쪽 위 **＋**
3. 맨 위 **새로운 단축어** 글자를 눌러 → **이름 변경** → `레시피 저장` 입력 → 완료

### 3-2. 공유 시트에 나오게 하기
1. 화면 아래쪽 **ⓘ** 아이콘(또는 맨 위 이름 옆 **⌄** → 세부사항)을 눌러요.
2. **공유 시트에 보기**를 켜고 → 오른쪽 위 **완료**
3. 편집 화면 맨 위에 **"공유 시트에서 [이미지 및 18개 이상] 입력을 받음"** 같은 줄이 생겨요.
   - 파란 글자(**이미지 및 18개 이상**)를 눌러 → 전부 체크 해제 → **URL**, **텍스트** 두 개만 체크
   - 같은 줄의 "입력이 없는 경우"는 **계속**으로 두면 돼요.

### 3-3. 동작 4개 추가하기
화면 아래 **🔍 동작 검색** 칸에 이름을 검색해서 눌러 추가해요. 추가한 순서대로 위에서 아래로 쌓여요.

**① 클립보드 가져오기**
- 검색: `클립보드` → **클립보드 가져오기**
- 설정할 것 없어요.

**② URL의 콘텐츠 가져오기**
- 검색: `URL의 콘텐츠` → **URL의 콘텐츠 가져오기**
- 추가되면 **URL** 자리에 `클립보드`(파란 말풍선)가 자동으로 들어가 있을 수 있어요.
  → 말풍선을 눌러 **지우기**, 그 자리에 **웹 앱 URL**을 붙여넣어요.
- 동작 오른쪽 **›(펼치기)** 를 눌러요.
  - **방법**: GET → **POST**
  - **요청 본문**: **JSON**
  - **＋ 새로운 필드 추가** → **텍스트**를 4번 반복해서 아래처럼 채워요.

| 키 | 값 |
|---|---|
| `action` | `save` (직접 입력) |
| `token` | *TOKEN 값* (붙여넣기) |
| `url` | 값 칸을 누르면 키보드 위에 변수 막대가 나와요 → **단축어 입력** 선택 |
| `caption` | 값 칸 → 키보드 위 변수 막대에서 **클립보드** 선택 |

  - 변수 막대에 원하는 게 없으면 막대 왼쪽 **변수 선택**을 누르고, 위쪽 동작에서 고르면 돼요.
  - 변수를 넣으면 글자가 아니라 **파란 말풍선**으로 보여야 맞아요.

**③ 사전 값 가져오기**
- 검색: `사전 값` → **사전 값 가져오기**
- **"[URL의 콘텐츠]에서 [키]에 대한 [값] 가져오기"** 처럼 보여요.
  - **키**를 눌러 `message` 입력
  - 앞부분이 **URL의 콘텐츠**로 연결돼 있는지만 확인

**④ 결과 보기** (또는 알림 보기)
- 검색: `결과` → **결과 보기** — 화면 가운데 작은 창으로 결과가 떠요.
  - 배너 알림이 좋으면 `알림` 검색 → **알림 보기**. iOS 버전에 따라 이름이 조금 달라요. 어느 쪽이든 똑같이 동작해요.
- 내용 자리에 **사전 값**이 자동으로 들어가요. (안 들어가 있으면 그 칸을 누르고 변수 막대에서 선택)

다 됐으면 오른쪽 위 **완료**.

### 3-4. 처음 한 번 해둘 설정
- **붙여넣기 허용**: 아이폰 **설정 → 앱 → 단축어 → 다른 앱에서 붙여넣기 → 허용**
  - 안 하면 실행할 때마다 "붙여넣기 허용?" 창이 떠요.
- 처음 실행하면 "script.google.com에 연결을 허용하겠습니까?"가 떠요 → **항상 허용**
- '알림 보기'를 썼다면 알림 권한을 물어볼 때 → **허용**

### 3-5. 테스트
1. 인스타에서 레시피 캡션이 있는 게시물을 열어 **캡션을 길게 눌러 복사**해요.
2. **종이비행기(공유)** → 아래쪽 **공유…** 또는 **더 보기** → 아이폰 공유 시트가 열려요.
3. 앱 아이콘 줄 아래 목록을 내려서 **레시피 저장**을 눌러요.
   - 안 보이면 맨 아래 **작업 편집…** → 레시피 저장 옆 **＋** 를 눌러 즐겨찾기에 추가해 두면 다음부터 위쪽에 보여요.
4. "저장했어요: 두부조림 (재료 8개 · 3단계) · 출처: 인스타그램" 알림이 뜨면 성공이에요.

네이버 블로그는 네이버 앱(또는 Safari)에서 글을 열고 **공유 → 레시피 저장**만 누르면 돼요.

### (선택) 저장할 때 이름 · 분류도 고르기
기본 단축어가 잘 되는 걸 확인한 다음에 추가해도 돼요. 위 **①과 ② 사이**에 넣어요. (동작을 길게 눌러 끌면 위치를 옮길 수 있어요)

| 동작 | 설정 |
|---|---|
| **입력 요청** | 질문: `메뉴 이름 (없으면 비워두기)` / 입력 유형: 텍스트 |
| **목록에서 선택** | 목록: `자동`, `반찬`, `국·찌개`, `밥`, `면`, `제과·제빵`, `디저트·간식`, `다이어트`, `기타` |

그리고 ② **URL의 콘텐츠 가져오기**의 JSON 필드에 두 개를 더 추가해요.
- `title` = **입력 결과** (변수)
- `category` = **선택된 항목** (변수)  — `자동`을 고르면 알아서 분류해요

### 쓰는 방법
**인스타 — 캡션에 레시피가 있을 때**
1. 게시물에서 **캡션을 먼저 복사**해요. 캡션을 길게 누르면 복사가 돼요.
2. 같은 게시물에서 **공유(종이비행기) → 더보기 → 레시피 저장**을 눌러요.
3. "저장했어요: 두부조림 (재료 8개 · 3단계) · 출처: 인스타그램" 알림이 뜨면 끝이에요.

**인스타 — 캡션 없이 영상에만 레시피가 있을 때**
- 캡션 복사 없이 바로 **공유 → 레시피 저장**을 누르면 **링크 모음** 탭에 따로 저장돼요.
- 링크 모음에서 **▶ 영상 보기**를 누르면 바로 인스타 영상이 열려요.
- 영상을 보면서 **내 메모**에 양념 비율 등을 적어두면 다음부터는 영상을 안 봐도 돼요.
- 나중에 캡션이 생기면 **📝 레시피로 정리하기**로 붙여넣어요. 레시피 탭으로 옮겨지고 출처 링크도 그대로 남아요.

**네이버 블로그**
- 네이버 앱이나 Safari에서 블로그 글을 열고 **공유 → 레시피 저장**만 누르면 돼요. 캡션 복사는 필요 없어요.
- 서버가 글 본문을 불러와서 재료 · 순서를 정리하고, 글 제목을 메뉴 이름으로 써요.
- 블로그 글은 인사말이나 이야기가 길어서 자동 정리가 틀릴 때가 있어요. 상세 → **수정**으로 고치거나 AI 정리(선택)를 켜면 훨씬 깔끔해져요.
- 비공개 글이나 서로이웃 공개 글은 불러올 수 없어서 링크 모음에 저장돼요.

**공통**
- 레시피 상세 화면 위쪽에 항상 **출처(인스타그램 / 네이버 블로그) 링크**가 보여요.
- 같은 게시물을 또 저장하면 "이미 저장된 레시피예요"라고 알려줘요.
- 클립보드에 예전 레시피 캡션이 남아 있으면 무시해요.
- 앱의 **＋ 추가**에서 링크를 붙여넣고 이름과 분류를 골라 저장할 수도 있어요.
- 이름, 분류, 출처 링크는 상세 화면 → **수정**에서 언제든 바꿀 수 있어요.

> 캡션이 길게 눌러도 복사되지 않는 게시물은 캡션 부분을 스크린샷 → 사진 앱에서 글자를 길게 눌러 복사(라이브 텍스트)하면 돼요.

## 코드를 새 버전으로 바꿀 때 (사진 기능 추가 등)
1. Apps Script 편집기에서 `Code.gs` 내용을 전부 지우고 새 내용을 붙여넣고 💾 저장
2. 함수 선택 칸에서 **`setup`** → ▷ 실행
   - 사진 기능 때문에 **구글 드라이브 권한**을 새로 물어봐요. 1-3과 같은 방법으로 **고급 → 이동 → 허용**
3. **배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포** (URL은 그대로)
4. 웹앱(`index.html`)도 GitHub에 새 파일로 덮어써요. 아이폰에서 앱을 다시 열면 반영돼요.

## 웹앱 기능 요약
- **레시피 / 링크 모음** 두 탭
- 메뉴명 · 재료 · 메모로 검색 (예: `두부`, `두부 대파`)
- 출처별 필터 (인스타그램 / 네이버 블로그)
- 분류(반찬, 국·찌개, 밥, 면, 제과·제빵, 디저트·간식, 다이어트, 기타) — 저장할 때 직접 고르거나 '자동' / 해본 것 · 안 해본 것 필터
- 최신순 · 별점순 · 이름순 정렬
- 대표 사진 1장: 자동으로 가져오거나 상세 화면 위쪽에서 **📷 대표 사진 추가 / 사진 바꾸기 / 삭제**
- 상세: 재료 · 양념 장보기 체크, 순서 번호, 팁, 별점, 해봤어요, 내 메모
- 정리가 틀렸으면 **수정**에서 한 줄에 하나씩 고치기, 또는 **다시 정리하기**
- 모든 레시피에 출처 링크 표시, 원본 글 보기

데이터는 구글 시트 `recipes`(레시피), `links`(링크 모음) 탭에 그대로 쌓여서 시트에서 직접 보거나 고쳐도 돼요. 재료와 순서는 셀 안에서 줄바꿈으로 구분돼요.

> 📷 사진은 웹앱에서 보이도록 드라이브에서 **'링크가 있는 사용자 보기'**로 저장돼요. 사진 주소를 아는 사람만 볼 수 있고, 레시피 내용은 토큰이 있어야 볼 수 있어요. 레시피를 삭제하면 사진도 드라이브 휴지통으로 옮겨져요.

## 문제가 생기면
| 증상 | 확인할 것 |
|---|---|
| "토큰이 맞지 않아요" | 웹앱 설정과 단축어의 token 값이 `setup` 로그 값과 같은지 |
| 알림에 아무것도 안 나오거나 이상한 글자가 나옴 | ②의 방법이 **POST**, 요청 본문이 **JSON**인지 / ③의 키가 정확히 `message`인지 |
| 단축어 실행 후 이상한 HTML이 보임 | 배포 **액세스 권한이 "모든 사용자"**인지, URL이 `/exec`로 끝나는지 |
| 코드를 고쳤는데 반영이 안 됨 | 배포 관리에서 **새 버전**으로 다시 배포했는지 |
| 정리가 자주 틀림 | 상세 → 수정으로 고치거나, AI 정리(선택)를 켜기 |
| 사진이 안 붙음 | 인스타는 서버 접근을 막는 경우가 많아서 자동으로 못 가져올 수 있어요. 상세 → 📷 대표 사진 추가로 스크린샷을 올리면 돼요 |
| 블로그가 링크 모음으로만 감 | 비공개·이웃공개 글인지 확인. 공개 글인데도 그렇다면 링크 상세 → 레시피로 정리하기에 본문을 복사해 붙여넣기 |
