# 🍳 레시피 노트 — 설치 가이드

인스타 캡션과 네이버 블로그 글에서 레시피를 뽑아 재료 · 양념 · 순서로 정리해 모아보는 앱이에요.

```
인스타 / 네이버 블로그 [공유] → 단축어 "레시피 저장" → Apps Script(정리) → 구글 시트
                                                                        ├ recipes 탭: 정리된 레시피 (+ 출처 링크)
                                                                        └ links 탭: 레시피가 없는 링크 모음
                                          아이폰 홈 화면 웹앱(index.html)에서 [레시피] [링크 모음] 탭으로 보기
```

| 상황 | 결과 |
|---|---|
| 인스타 + 캡션 복사함 | 레시피로 정리 · 출처 링크 함께 저장 |
| 인스타 + 캡션 없음 | **링크 모음**에 따로 저장 (나중에 캡션 붙여넣으면 레시피로 이동) |
| 네이버 블로그 | 링크만 공유하면 글 본문을 불러와서 레시피로 정리 · 출처 링크 함께 저장 |

| 파일 | 역할 |
|---|---|
| `Code.gs` | 구글 Apps Script 서버. 캡션·블로그 글 정리, 중복 확인, 시트 저장 |
| `index.html` | 아이폰에서 보는 웹앱 (GitHub Pages에 올림) |

---

## 1. 구글 시트 + Apps Script (10분)

1. 구글 시트를 새로 만들고 이름을 `레시피 노트`로 정해요.
2. 메뉴 **확장 프로그램 → Apps Script**를 열어요.
3. 기본 `Code.gs` 내용을 모두 지우고, 받은 `Code.gs`를 붙여넣은 뒤 저장해요.
4. 위쪽 함수 선택에서 **`setup`**을 고르고 **실행**해요.
   - 처음엔 권한 허용 창이 떠요 → 내 계정 선택 → "고급" → "(안전하지 않음)으로 이동" → 허용
   - 아래 실행 로그에 나온 **`TOKEN: xxxxxxxx`** 값을 복사해 두세요.
   - 시트에 `recipes`, `links` 탭이 생겨요.
5. 오른쪽 위 **배포 → 새 배포** → 유형 **웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   - 배포 → 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해 두세요.

> 💡 `testParse` 함수를 실행하면 샘플 캡션이 어떻게 정리되는지 로그로 볼 수 있어요.
>
> ⚠️ 이전 버전을 이미 배포했다면 새 `Code.gs`를 붙여넣고 **`setup`을 한 번 더 실행**한 뒤 다시 배포하세요. (`links` 탭과 `source` 열이 추가돼요)
>
> ⚠️ 나중에 `Code.gs`를 고치면 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전**으로 다시 배포해야 반영돼요. URL은 그대로예요.

### (선택) AI 정리 켜기
기본은 무료 규칙 기반 정리예요. 캡션 형식이 들쭉날쭉해서 정리가 자주 틀리면 AI 정리로 바꿀 수 있어요.

- Apps Script 왼쪽 **⚙️ 프로젝트 설정 → 스크립트 속성 → 속성 추가**
- 속성 `CLAUDE_API_KEY`, 값에 Claude API 키를 넣고 저장
- 키를 지우면 다시 무료 규칙 정리로 돌아가요. 이미 저장된 레시피는 상세 화면의 **다시 정리하기**로 새로 정리할 수 있어요.

## 2. 웹앱 올리기 (GitHub Pages)

1. GitHub에 새 저장소(예: `recipe-note`)를 만들고 `index.html`을 올려요.
2. 저장소 **Settings → Pages → Branch: main / root → Save**
3. 잠시 후 나오는 주소(`https://아이디.github.io/recipe-note/`)를 아이폰 **Safari**로 열어요.
4. 오른쪽 위 **⚙︎ 설정**에 1단계의 **웹 앱 URL**과 **TOKEN**을 넣고 **연결**을 눌러요.
5. Safari 공유 버튼 → **홈 화면에 추가** → 앱처럼 쓰면 돼요.

> 서버 주소와 토큰은 아이폰 브라우저에만 저장되고 GitHub에는 올라가지 않아요. 그래서 저장소가 공개여도 다른 사람이 레시피를 볼 수 없어요.

## 3. 단축어 "레시피 저장" 만들기 (5분)

아이폰 **단축어** 앱 → **＋** → 이름을 `레시피 저장`으로 정해요.

1. 화면 아래 **ⓘ(세부사항)** → **공유 시트에 보기** 켜기
   - 맨 위 "공유 시트 입력"을 **URL**과 **텍스트**만 남기고 나머지는 끄기
2. 아래 동작을 순서대로 추가해요.

| # | 동작 | 설정 |
|---|---|---|
| 1 | **클립보드 가져오기** | — |
| 2 | **URL의 콘텐츠 가져오기** | URL: *웹 앱 URL* 붙여넣기<br>▸ 펼쳐서 **방법: POST**, **요청 본문: JSON**<br>필드 4개 추가 (모두 텍스트):<br>`action` = `save`<br>`token` = *TOKEN 값*<br>`url` = **단축어 입력** (변수)<br>`caption` = **클립보드** (변수) |
| 3 | **사전 값 가져오기** | 키: `message` / 사전: **URL의 콘텐츠** |
| 4 | **알림 표시** (또는 "결과 보기") | 내용: **사전 값** |

3. 오른쪽 위 **완료**.

### (선택) 저장할 때 이름 · 분류도 고르기
캡션 없는 영상 레시피를 자주 저장한다면 추가해 두면 좋아요. 위 표의 **1번과 2번 사이**에 넣어요.

| 동작 | 설정 |
|---|---|
| **입력 요청** | 질문: `메뉴 이름 (없으면 비워두기)` / 입력 유형: 텍스트 |
| **목록에서 선택** | 목록: `자동`, `반찬`, `국·찌개`, `밥`, `면`, `제과·제빵`, `디저트·간식`, `다이어트`, `기타` |

그리고 2번 **URL의 콘텐츠 가져오기**의 JSON 필드에 두 개를 더 추가해요.
- `title` = **입력 결과** (변수)
- `category` = **선택된 항목** (변수)  — `자동`을 고르면 알아서 분류해요

### 쓰는 방법
**인스타 — 캡션에 레시피가 있을 때**
1. 게시물에서 **캡션을 먼저 복사**해요. 캡션을 길게 누르면 복사가 돼요.
2. 같은 게시물에서 **공유(종이비행기) → 더보기 → 레시피 저장**을 눌러요.
3. "저장했어요: 두부조림 (재료 8개 · 3단계) · 출처: 인스타그램" 알림이 뜨면 끝이에요.

**인스타 — 캡션 없이 영상에만 레시피가 있을 때**
- 캡션 복사 없이 바로 **공유 → 레시피 저장**을 누르면 **링크 모음** 탭에 따로 저장돼요.
- 링크 모음에서 **▶ 영상 보기**를 누르면 바로 인스타 영상이 열려요.
- 영상을 보면서 **내 메모**에 양념 비율 등을 적어두면 다음부터는 영상을 안 봐도 돼요.
- 나중에 캡션이 생기면 **📝 레시피로 정리하기**로 붙여넣어요. 레시피 탭으로 옮겨지고 출처 링크도 그대로 남아요.

**네이버 블로그**
- 네이버 앱이나 Safari에서 블로그 글을 열고 **공유 → 레시피 저장**만 누르면 돼요. 캡션 복사는 필요 없어요.
- 서버가 글 본문을 불러와서 재료 · 순서를 정리하고, 글 제목을 메뉴 이름으로 써요.
- 블로그 글은 인사말이나 이야기가 길어서 자동 정리가 틀릴 때가 있어요. 상세 → **수정**으로 고치거나 AI 정리(선택)를 켜면 훨씬 깔끔해져요.
- 비공개 글이나 서로이웃 공개 글은 불러올 수 없어서 링크 모음에 저장돼요.

**공통**
- 레시피 상세 화면 위쪽에 항상 **출처(인스타그램 / 네이버 블로그) 링크**가 보여요.
- 같은 게시물을 또 저장하면 "이미 저장된 레시피예요"라고 알려줘요.
- 클립보드에 예전 레시피 캡션이 남아 있으면 무시해요.
- 앱의 **＋ 추가**에서 링크를 붙여넣고 이름과 분류를 골라 저장할 수도 있어요.
- 이름, 분류, 출처 링크는 상세 화면 → **수정**에서 언제든 바꿀 수 있어요.

> 캡션이 길게 눌러도 복사되지 않는 게시물은 캡션 부분을 스크린샷 → 사진 앱에서 글자를 길게 눌러 복사(라이브 텍스트)하면 돼요.

## 웹앱 기능 요약
- **레시피 / 링크 모음** 두 탭
- 메뉴명 · 재료 · 메모로 검색 (예: `두부`, `두부 대파`)
- 출처별 필터 (인스타그램 / 네이버 블로그)
- 분류(반찬, 국·찌개, 밥, 면, 제과·제빵, 디저트·간식, 다이어트, 기타) — 저장할 때 직접 고르거나 '자동' / 해본 것 · 안 해본 것 필터
- 최신순 · 별점순 · 이름순 정렬
- 상세: 재료 · 양념 장보기 체크, 순서 번호, 팁, 별점, 해봤어요, 내 메모
- 정리가 틀렸으면 **수정**에서 한 줄에 하나씩 고치기, 또는 **다시 정리하기**
- 모든 레시피에 출처 링크 표시, 원본 글 보기

데이터는 구글 시트 `recipes`(레시피), `links`(링크 모음) 탭에 그대로 쌓여서 시트에서 직접 보거나 고쳐도 돼요. 재료와 순서는 셀 안에서 줄바꿈으로 구분돼요.

## 문제가 생기면
| 증상 | 확인할 것 |
|---|---|
| "토큰이 맞지 않아요" | 웹앱 설정과 단축어의 token 값이 `setup` 로그 값과 같은지 |
| 단축어 실행 후 이상한 HTML이 보임 | 배포 **액세스 권한이 "모든 사용자"**인지, URL이 `/exec`로 끝나는지 |
| 코드를 고쳤는데 반영이 안 됨 | 배포 관리에서 **새 버전**으로 다시 배포했는지 |
| 정리가 자주 틀림 | 상세 → 수정으로 고치거나, AI 정리(선택)를 켜기 |
| 블로그가 링크 모음으로만 감 | 비공개·이웃공개 글인지 확인. 공개 글인데도 그렇다면 링크 상세 → 레시피로 정리하기에 본문을 복사해 붙여넣기 |
